# CO-AAP Interactive Reporting Reader

Vercel-ready React/Vite prototype for A14 DISCOVER / CO-AAP reporting, training manual, evidence continuity, GrantOS, and Quest Rivals documentation.

## Local run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Vercel settings

- Framework: Vite
- Build command: `npm run build`
- Output directory: `dist`

## Safety note

This prototype does not include private student data. Keep it demo-only until authentication, permissions, privacy review, FERPA/COPPA handling, storage, and audit logs are added.
